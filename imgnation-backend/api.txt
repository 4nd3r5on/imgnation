> # POST /uploads ----------------
[REQUEST]
Content-Type: multipart/form-data

First data part should be named "metadata" and contain JSON of format:

```json
{"metadata": [
    {
      "tags": [<string>],
      "access": {
        "level": <0 -- anyone, 1 -- authorized, 2 -- private>,
        "allowed_user_emails": [<string>]
      },
      "description": <string>
    }
]}
```

Next parts should be files (with provided filename and content type)
Number of files should correspond to the provided metadata items count

Metadata should correspond file parts order

[REPONSE]
Content-Type: application/json
```json
{
  "results": [
    "successful": <bool>
    "upload_id":  <?string>
    "filename":   <?string>
    "error":      <?string>
  ]
}
```
